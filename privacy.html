Privacy policy

Updated October 21, 2026

Finance OS is a personal desktop finance application operated by its owner. This policy explains the application's Google account access, local financial processing and this public information website.

Google data accessed and its purpose

With the owner's authorization, Finance OS uses the Gmail API's gmail.readonly permission to read messages, message metadata and attachments. This includes financial purchase notifications and PDF account statements selected for processing. A dedicated mailbox receiving forwarded financial messages is the intended configuration.

This permission allows reading the whole authorized mailbox. Filters are processing controls, not a per-sender or per-label permission boundary. Finance OS does not request Gmail permissions to send, modify or delete messages.

The data is used to capture source evidence, extract transaction information, propose spending categories, support the owner's review, reconcile statements and prepare personal financial summaries. It is not used for advertising, sale of data, unrelated profiling or training or fine-tuning AI models.

Local storage and AI processing

Downloaded messages, attachments, extracted text, transaction records, decisions, financial questions and AI responses are stored on the owner's computer. The financial assistant uses a local AI model without an automatic fallback to hosted AI services. The financial model does not initiate payments or independently approve accounting decisions.

Operational databases and original files do not have application-level encryption at rest. Access depends on the owner's Windows account, file permissions and device security. OAuth tokens are protected using Windows user-bound DPAPI. This does not protect data from software already running with the same user's authority.

External services and data sharing

Google provides account authorization and Gmail storage, including the original or forwarded messages in the authorized mailbox. Local processing does not remove those Google-hosted copies. Finance OS does not sell Google user data or send financial content to advertising services.

The owner may export an encrypted backup and place that encrypted archive with a cloud storage provider they choose. That is an owner-controlled action. The owner is responsible for safeguarding the recovery phrase separately from the archive.

Finance OS's use of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention, revocation and deletion

Locally captured evidence and financial records are retained under the owner's control until the owner removes them. Revoking Google access stops future authorized Gmail API access; it does not automatically delete previously downloaded files, records or backups.

The owner can revoke access through Google Account permissions. To remove captured data, the owner must remove the relevant local records and copies, and separately manage any mailbox messages or cloud backups. Contact the address below for help with these controls. The public website does not accept deletion requests containing financial documents.

This public website

This site contains application information and these policies only. It has no forms, account login, analytics scripts, advertising, financial uploads or connection to the owner's financial database. Its pages do not set application cookies.

When hosted on GitHub Pages, GitHub processes website requests and records visitor IP addresses for security purposes as described in the GitHub Privacy Statement. Website hosting does not give GitHub access to the local Finance OS workspace.

Contact and changes

Application support and privacy contact: josgonzalez330@gmail.com. Do not send passwords, OAuth tokens, recovery phrases or account statements to this address as part of a support request.

This policy will be updated when data practices change. New uses of Google user data require appropriate disclosure and any consent required by Google's policies.
